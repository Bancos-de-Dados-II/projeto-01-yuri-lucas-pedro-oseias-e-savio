# GeoPB Comunidades

Aplicação web para visualização e análise de comunidades da Paraíba através de mapas interativos.

## Descrição

O projeto utiliza dados geográficos dos municípios da Paraíba e os integra com informações de comunidades, permitindo a visualização dos dados em um mapa interativo.

## Funcionalidades

* Visualização dos municípios da Paraíba no mapa
* Busca de municípios
* Filtro por quantidade de comunidades
* Exibição de informações detalhadas dos municípios
* Gráficos com indicadores das comunidades
* Geolocalização do usuário
* Geocodificação através do Leaflet

## Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
* Leaflet
* Chart.js
* GeoJSON

## Bases de Dados

* GeoBR
* IBGE
* Dados de Comunidades da Paraíba

## Como Executar

1. Clone o repositório.
2. Abra o projeto no VS Code.
3. Execute utilizando a extensão Live Server.
4. Acesse a aplicação pelo navegador.

## Estrutura do Projeto

* `index.html` - Interface principal
* `style.css` - Estilos da aplicação
* `script.js` - Lógica da aplicação
* `PB_Municipios_2025.json` - Dados geográficos dos municípios
* `comunidades_pb.json` - Dados das comunidades
* `c99a759c17b06bcac311736d48b4fb25.json` - Dados complementares do IBGE
